# Nexium Coursework Package

Nexium is a premium and sustainable e-commerce concept focused on brand-new mobile phones, tablets, premium accessories, and certified pre-owned devices.

## Included Deliverables

- `index.html` - high-fidelity web storefront prototype
- `mobile-app.html` - mobile app UX prototype showcase
- `styles.css` - shared brand system and component styling
- `script.js` - lightweight interactions for filtering and comparison
- `docs/project-charter.md` - project charter report
- `docs/solution-architecture.md` - solution architecture report
- `docs/release-plan.md` - phased release plan report
- `docs/ui-ux-design-specification.md` - UI/UX specification report

## How To View

1. Open `index.html` in a browser for the web application concept.
2. Open `mobile-app.html` in a browser for the mobile application concept.
3. Read the files in `docs/` for the supporting SPM deliverables.

## Notes

- This package is design-led and coursework-oriented.
- The prototype uses mock content and static interactions only.
- The visual direction is inspired by dense retail merchandising patterns but reworked for the Nexium brand.
